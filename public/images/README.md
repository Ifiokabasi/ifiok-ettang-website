# Images

Drop your real photos/frame-grabs into this folder (and `stories/`, `now/`,
`about/` subfolders) using the filenames already referenced in the
components, or update the `src` paths in:

- `components/Hero.tsx` → `hero-hz-thumb.jpg`
- `components/StoriesSection.tsx` → `stories/*.jpg`
- `components/NowSection.tsx` → `now/*.jpg`
- `components/AboutSection.tsx` → `about/ifiok-portrait.jpg`

The Figma file's own image assets are exported to temporary URLs that expire
after 7 days, so they aren't embedded directly in this handoff — swap in your
real photography/film stills instead.
